The following maps have no default trader locations and spawns setup yet:

- Banov
- DeerIsle
- Livonia (Enoch)
- Esseker
- Iztek
- Rostow
- Valning

If you still want to use the market system on one of these maps, you can use the DayZ-Editor mod (https://steamcommunity.com/sharedfiles/filedetails/?id=2250764298&searchtext=DayZ+Editor)
to create your own locations and place the needed trader NPCs or objects.
The mod allows you to place down objects/NPCs and export them to the needed format for Expansion (.map files).
More on how to setup the market system can be found on the offical DayZ Expansion Wiki: https://github.com/salutesh/DayZ-Expansion-Scripts/wiki/%5BServer-Hosting%5D-The-Market-System
